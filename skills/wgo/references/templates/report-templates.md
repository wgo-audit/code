# Synthesis Report Templates

Replace prompts in completed artifacts. Keep templates in English and translate
generated reports at synthesis when requested.

## Audit Index

```markdown
# Audit Index

## Start Here
## Audience Routes
## Evidence Boundary
```

## Executive Summary

```markdown
# Executive Summary

## Mandate, Boundary, And Bottom Line
## Current Product And Control Position
## Material Risks, Unknowns, And Decisions
### Decision-Useful Conclusions
Include only when material evidence changes a decision, priority, sequence,
claim, or stop condition. Do not use a target count.
### Decisions Now
List canonical `decision-needed` items only when material ones exist.
### Evidence Needed
List canonical `verification` items only when material ones exist.
### Implementation Corrections
List canonical `action` items only when material ones exist. Order within each
lane; do not present all P1 items as one queue.
## Evidence-Supported 30–90 Day Plan
| Timing | Accountable owner | Action | Evidence basis | Exit evidence |
|---|---|---|---|---|
## Reader Routing And Limits
```
